# Punto y aparte · Landing

Web estática de un solo archivo (`index.html`).

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub (index.html en la raíz).
2. En Vercel: Add New → Project → importa el repositorio.
3. Framework Preset: **Other**. Sin comando de build. Output directory: raíz.
4. Deploy.

## Integraciones
- Inscripciones → Google Sheets + email de confirmación (Apps Script) y aviso en Slack.
- Textos legales: `index.html#privacidad`, `#aviso-legal`, `#cookies`.
